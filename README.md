## Getting Started

Utilizar conceptos como Backtraking para soluccionar problemas complejos.

## Folder Structure

El espacio de trabajo contiene tres folders donde:

- `src`: es el folder que contiene el programa principal
- `lib`: the folder to maintain dependencies
- `Files`: es el folder que contiene los archivos.txt

## Dependency Management

The `JAVA PROJECTS` view allows you to manage your dependencies. More details can be found [here](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).
